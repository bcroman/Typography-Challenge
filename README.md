# CSS Typography Challenge

## Project Description
This project is a CSS Typography Challenge built using HTML and CSS.

The project focuses on experimenting with different font families, sizes, weights, line heights, letter spacing and visual hierarchy to create a visually appealing and responsive text layout.

## Features
- Custom font families using Google Fonts
- Large handwritten headline
- Different font sizes and weights
- Italic text and uppercase subtitles
- Custom letter spacing and line heights

## Technologies Used
- HTML5
- CSS3
- CSS Flexbox
- CSS Typography
- Google Fonts

## How to Run
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. View the typography layout.
5. Experiment with font sizes, weights and spacing.
